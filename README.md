# Обработка заявки на перевозку фурой

Пет-проект для портфолио системного аналитика.

## О проекте

Клиент отправляет заявку на перевозку груза по телефону или email. Менеджер согласовывает перевозку со службой эксплуатации, выставляет счёт на предоплату. После оплаты логист назначает машину. Менеджер сопровождает рейс, после завершения отправляет закрывающие документы и контролирует оплату (если по договору отсрочка).
